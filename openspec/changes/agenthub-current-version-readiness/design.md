# Design

Use the existing developer launcher and Node standard libraries. Preserve the
8000/3000 defaults, explicit overrides, fixed optional demo API 5174 and fail-on-
occupied-port contract. Distinguish EADDRINUSE, EACCES and other bind errors.
Only Windows EACCES may query fixed, read-only `netsh interface ipv4 show
excludedportrange protocol=tcp`; parse bounded numeric range rows independently
of localized headings. Failed diagnostics must remain unknown, not prove a range.
Probe a small fixed candidate list, excluding current peer/browser-restricted
ports, and report a command preserving every selected port/demo option. A probe
does not reserve its port: startup must recheck. Never change system reservations.

Keep the main dev checkout and its existing adapters. Make execution extraction
behavior-preserving: ownership/final terminal transactions stay authoritative;
move whole cohesive responsibilities with explicit dependencies and retain public
engine entrypoints used by callers/tests. Select precise extraction boundaries
after the startup task passes, before touching the engine. Verify cancellation,
stale ownership, provider release, generated review and pipeline behavior.

After code fixes and regression checks, freeze implementation/policy/operator
hashes before the ten-task cohort. Use separate test databases and assigned
worktrees; never use the product database as an evaluation fixture. Reuse the
existing trusted workflow harness, native Planner/coding/QA, fixed validation and
source-bound receipts. Report strict versus independent business results, actual
retry paths, role/stage elapsed time and known/unknown token usage separately.
Failures remain failures; repair probes are a separate cohort. If a real-task
failure requires source changes, close that cohort and freeze a new version.

The reproducible Chinese operator is a developer script, not an Agent tool or
API endpoint. Prepare/test it as part of final code preparation before live
evaluation. Set current-interpreter bytecode suppression and isolated temporary,
database and provider configuration before importing runtime services. Forward
only model transport settings from the operator-owned local file. Preservation
failure invalidates the cohort report itself before a successful summary can be
printed; preparation failures retain a terminal evidence state. Final regression
may be partitioned by disjoint whole test files into separate databases, without
installing a parallel-test plugin; retain complete file coverage and unique counts.

Showcase selection is drawn only from valid final-version samples, with process,
Diff/review and real application preview provenance. Historical 50-task figures
remain historical; ten repetitions are not ten distinct business requirements.
