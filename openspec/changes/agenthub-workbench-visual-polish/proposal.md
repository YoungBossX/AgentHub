# Workbench visual polish

## Why

The workbench relies on repeated outlines and cool gray fills. The user supplied
ten concrete visual/interaction rules and requested implementation in the existing UI.

## What Changes

- Warm neutral light/dark surface tokens, borderless panels, balanced composer.
- Visible double-shadow focus, dark font weights reduced by 40, inline icon
  alignment, tabular numbers and pretty paragraph wrapping.
- Incremental text blur reveal, Grid disclosures, parameter-derived spring
  feedback and copy confirmation that expires after 2.5 seconds.

## Impact

Frontend only. Preserve panes, themes, evidence, process/results views, keyboard
resizing, adapters and all database records. No new dependencies or paid API runs.
