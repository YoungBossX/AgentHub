# 修复数据库外键执行和事件编号并发

## Why

当前 SQLite 运行连接未开启外键，事件编号在持有写锁前读取最大值，
隔离实验已复现孤立 Message 和重复事件序号。用户要求先修复这两项，再推进 PostgreSQL，
保留数据，新增备份和临时文件存放在 E:\Docker，并清理被替代的内容。

## What Changes

- 为业务连接显式开启并确认外键；检查父子写入与删除顺序。
- 新增固定 v2 revision，保留不可变 v1；为 TaskRun 事件增加组合唯一索引。
- 对受支持历史库核验全部预期关系，离线补齐缺失外键；不删除或重编号历史记录。
- 在持有数据库写锁后分配事件序号，保留调用方状态事务和 SSE 时间游标语义。
- 沿用独占维护、一致备份、隔离演练、全旧值/BLOB 验证及失败回执。
- 验收后清理实际被替代代码和本专项确认废弃的临时副本；保护运行数据和历史证据。
