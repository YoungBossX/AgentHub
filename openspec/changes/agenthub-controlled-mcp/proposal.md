# Controlled MCP document tools

Integrate a first read-only MCP server with the existing Codex execution path.
Workspace settings select document tools and default Agent bindings. AgentHub
hosts a stateless Streamable HTTP gateway; runtime tokens are ephemeral and bound
to the actual TaskRun execution generation. Documents come only from bounded
assigned-target documentation. Record real discovery/call receipts and show them
in the workbench. Other adapters explicitly report unsupported compatibility.

This focused task does not add arbitrary server launch commands, credentials,
remote endpoints, a marketplace or write tools. It provides a real MCP transport
and model tool path for the useful local documentation use case.
