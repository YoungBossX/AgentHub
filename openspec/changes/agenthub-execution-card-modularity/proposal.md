# Separate execution ownership and task-card presentation

After the native-QA evaluation and business-contract tasks, reduce maintenance
cost in the 4,103-line execution engine and large task-card entrypoint. Extract
cohesive ownership records/lease checks/renewal into an independent backend module,
and plan data, plan summary and artifact cards into focused frontend modules.
Keep behavior, persisted formats, public import paths, permissions and UI intact.
No additional platform feature, dependencies, migration or runtime restart.
