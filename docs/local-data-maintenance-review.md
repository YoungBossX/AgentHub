## 1.1 一致备份与恢复：本地完成

新增开发者离线入口 `scripts/local-data.py`，仅使用已安装 Python 和本机 Git。
API 生命周期持有数据库旁的 OS 共享锁；维护要求独占锁、配置的回环 API 端口停止监听、
SQLite 写事务保留，以及无活动 TaskRun/目标锁/预览作业/运行中预览。
不会停止现有进程，旧 API 尚未采用生命周期锁时仍需先停机；数据库写保留不能阻止独立编辑器。

快照包括 SQLite backup API 读取的 WAL 数据、原始 Git 管理信息、注册且位于 `.worktrees`
中的会话/执行/集成工作树，以及当前已跟踪和未被忽略的源文件。保留暂存、未暂存、删除、
未跟踪文件、消息和附件字节。两遍来源文件/哈希校验后发布 manifest；文件变化、失联/外来
工作树、Git 锁、外部 object store、子模块、链接/硬链接或超限时拒绝完整快照。
固定上限 100,000 文件、4 GiB 总量、单文件 512 MiB。

依赖、被忽略的构建/运行输出、`.env*`、`secrets` 和外部注册项目宿主源目录不在备份范围。
快照包含数据库用户数据和原始 Git 元数据/本地配置，未加密，不是可公开发布的项目证据包。
SHA-256 用于发现损坏，不是第三方备份的可信认证；只恢复自己生成的本地快照。

`verify` 检查 manifest/逐文件哈希、大小/模式、清单完整性、SQLite integrity/foreign-key。
`restore` 只向新目录复制，全程持有目标数据库独占锁，逐文件以独占新建模式写入；
独立演练只改复制出的 Git 配置和指针，核对 HEAD、index 条目、
对象完整性与 SQLite，保留 DB 原路径和历史证据不变。演练不等于可直接启动的迁移副本。
`--original-paths --confirm-id <snapshotId>` 只能恢复到完全缺失的原仓库路径；不会覆盖已有目录。
失败保留部分输出供检查，不自动删除/重试或把失败当成功。
